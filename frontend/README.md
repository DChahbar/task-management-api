# Task Management — Frontend

React + TypeScript client for this project. **Setup, architecture, and deployment** are documented in the [root README](../README.md) and [DEPLOYMENT.md](../DEPLOYMENT.md).

## Quick commands

```bash
npm install
cp .env.example .env
npm run dev          # http://localhost:5173
npm run build        # production build
npm run preview      # preview build on :4173
```

Start the API from the repo root before signing in (`uvicorn app.main:app --reload`).
